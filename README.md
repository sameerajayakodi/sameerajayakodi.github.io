# sameerajayakodi.github.io

Personal portfolio of Sameera Jayakodi — software engineer, full-stack & AI automation.

Live: https://sameerajayakodi.github.io/

## Stack

React 19 · Vite · Tailwind CSS v4 · Motion. Fully static; deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Editing content

All copy lives in `src/data.ts` (profile, stats, experience, projects, skills, education). Project screenshots go in `public/work/`, and the downloadable CV is `public/Sameera_Jayakodi_CV.pdf`.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build into dist/
```
